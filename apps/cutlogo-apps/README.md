# Daily Free Apps

围绕真实需求制作免费、开源的小型 Android APP，并用可运行的作品、清晰文档和开发记录展示工程能力。

首发项目：[轻码 / Quiet QR](apps/quiet-qr/README.md)。定位：离线二维码生成、图片识别与 PNG 导出。

[市场调研](research/2026-11-01-google-play.md) · [每日交付流程](docs/daily-workflow.md)

这里是本地项目，尚未关联 GitHub 账号或发布到 Google Play。每日是目标节奏，只有通过检查的版本才交付；不制造无意义提交或虚构下载、Star 数据。
