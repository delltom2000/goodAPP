# 0.4.0 验证记录（2026-11-01）

- Android 正式包和测试包的 Java 编译、DEX 转换、资源打包、四架构库打包、zipalign、v2/v3 签名校验通过。
- 桌面 OpenCV 对仓库内 640×360、9 秒样片进行 18 帧采样，自动得到 5 个候选框：左上固定角标、右下主 Logo 与署名、左下主 Logo 与署名。候选框是启发式结果，非语义检测。
- 全帧匹配实验发现，透明角标在部分低对比度画面低于全帧搜索的 0.55 阈值，已为采样确认的位置添加局部搜索（阈值 0.38）；预览和导出均跳过仍低于阈值的目标；不宣称所有帧的角标均可去除。主 Logo 在已抽查的 1、4 秒画面中可全帧匹配，7 秒画面中某些模板仍低于阈值，存在漏检；未承诺逐帧全部去除。
- 新设备测试包含自动识别多标识、预览选区、修补区域外像素保持、空白帧拒绝匹配、取消，以及自动计划导出的音轨/时长检查。测试包已编译，未执行。
- 未下载或启动模拟器。未进行手机安装、交互、性能或修补质量验收。

验收：导入视频后主按钮可用，无需设置选区；自动流程完成后可播放和另存；无目标视频提示补选；可选固定角标勾选但未框选不阻塞导出；手动定位和预览仍可使用；取消后原片和上次成功结果保留。
