# 离线语音与翻译组件

本发布包使用 Windows x64 CPU 推理，音轨、转写和译文均在本机处理。模型来自下列项目。

- **Whisper small.en** 由 OpenAI 训练，遵循 MIT 许可证。发布包使用 whisper.cpp 项目提供的 Q5_1 量化权重，文件 SHA-256 为 `bfdff4894dcb76bbf647d56263ea2a96645423f1669176f4844a1bf8e478ad30`。[权重](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-small.en-q5_1.bin) · [模型项目](https://github.com/openai/whisper)
- **whisper.cpp 1.8.2** 提供 CPU 推理程序。使用该版 Windows x64 发行包中的命令行程序和四个计算库，许可证见同目录 `whisper-cpp-MIT.txt`。[源码与发行版](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.8.2)
- **OPUS-MT 英译简体中文模型** 来自 Argos 的 `translate-en_zh-1_9.argosmodel`。原模型作者为 Jörg Tiedemann 与 Santhosh Thottingal，相关论文为 *OPUS-MT — Building open translation services for the World*（EAMT 2020）。模型随附 README 标注原模型使用 CC BY 4.0。Xread 随包保留了转换后的模型权重、分词器、元数据和作者说明，省略了通用分句器。原 Argos 压缩包 SHA-256 为 `433e7c4f034d87fbe2353161e05f18646d7999452f801a4e1f0378522b9850ab`。[Argos 模型索引](https://github.com/argosopentech/argospm-index) · [模型包](https://argos-net.com/v1/translate-en_zh-1_9.argosmodel) · [许可条款](https://creativecommons.org/licenses/by/4.0/)
- **Python 3.12.10 Windows embeddable package** 提供运行时，许可及第三方声明见 `runtime/LICENSE.txt`。[发行页](https://www.python.org/downloads/release/python-31210/)
- **CTranslate2 4.6.0、SentencePiece 0.2.1、NumPy 2.2.6、PyYAML 6.0.4 与 setuptools 80.9.0** 采用 PyPI 发布的 Windows 或通用 wheel，许可证和元数据随本目录及 `runtime/packages` 提供。[CTranslate2](https://github.com/OpenNMT/CTranslate2) · [SentencePiece](https://github.com/google/sentencepiece)
- **Microsoft Visual C++ 运行库** 用于 Windows 原生推理组件。相关 DLL 属于 Microsoft Corporation。[运行库说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)

## 中文配音

- **Kokoro-82M v1.1-zh** 来自 hexgrad，使用 Apache 2.0。标准模式采用 sherpa-onnx 发布的 INT8 ONNX 模型，输出 24 kHz 音频。Xread 使用原版权重、声线、英中词表及数词处理规则。权重许可保存在 `models/kokoro-int8-multi-lang-v1_1/LICENSE`。下载压缩包 SHA-256 为 `259c9c8bc906d6078e4e0570421885dabb68b539c2f970fcbb890a58eeaf3e9c`。[模型及作者说明](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh) · [ONNX 发行与声线对照](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html)
- **PaddleSpeech FastSpeech2 与 HiFiGAN 1.1.0** 在快速模式中分别把音素转成声学特征、把声学特征转成 24 kHz 语音。两款模型均采用 AISHELL-3 普通话语料训练。模型、音素编号和说话人映射直接来自飞桨官方 ONNX 发行包，保留上游文件内容。PaddleSpeech 项目及 AISHELL-3 语料均采用 Apache 2.0，项目许可全文见 `PaddleSpeech-Apache.txt`。声学模型原始压缩包 SHA-256 为 `7c99e6ea39983925d68c8a4348a369eeee05fb7774523c8896b31c4f0b8ddfee`，声码器压缩包为 `9e36b1257cab724c65828ba799338f990f342742c28f4683b31327f6aa7b71d4`。[官方模型列表](https://paddlespeech.readthedocs.io/en/latest/released_model.html) · [训练、导出及说话人参数说明](https://github.com/PaddlePaddle/PaddleSpeech/tree/develop/examples/aishell3/tts3) · [AISHELL-3 数据集许可](https://www.openslr.org/93)
- 快速模式沿用 **Icefall AISHELL-3** 发布包中的中文发音词典，按最长词条区分“银行”和“行为”等多音词。英文技术词采用中文读名或逐字母拼读，整句共用同一说话人。词典来源压缩包的 SHA-256 为 `ab468db3a3308cdd861495e0db2f25d79418a0c00639f74944c7cdf5dd8c6ec1`。[Icefall 上游发布及许可](https://huggingface.co/csukuangfj/icefall-tts-aishell3-vits-low-2024-04-06)
- **sherpa-onnx 2.0.2** 使用 Apache 2.0，Python 运行包与原生库来自 PyPI Windows x64 wheel。许可证随 `runtime/packages/sherpa_onnx-2.0.2.dist-info/licenses` 提供。自带的 Microsoft ONNX Runtime 使用 MIT 许可。[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) · [ONNX Runtime](https://github.com/microsoft/onnxruntime)

### 固定声线

选定音色与质量后，每句中文和英文术语都由该档的同一说话人合成。标准模式使用 Kokoro 上游表的 `zf`（中文女声）或 `zm`（中文男声）编号。快速模式在 `models/paddlespeech-aishell3-24k/speaker_id_map.txt` 查询说话人编号，再按同一标识核对语料发布者提供的 `models/vits-icefall-zh-aishell3/spk-info.txt` 性别列。[Kokoro 编号与性别映射](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html) · [AISHELL 官方说话人元数据](https://huggingface.co/datasets/AISHELL/AISHELL-3/blob/main/spk-info.txt)

| 界面音色 | 标准模式 · Kokoro | 快速模式 · AISHELL-3 |
| --- | --- | --- |
| 自然女声（默认） | 22 · zf_036 | 47 · SSB0395 · female |
| 明亮女声 | 32 · zf_049 | 31 · SSB0315 · female |
