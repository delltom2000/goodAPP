Xread 2.3  |  Windows x64 中文视频译制台

首次启动
完整解压 ZIP，双击 Xread 文件夹里的 Start Xread.cmd。它会在后台启动本机服务并打开工作台窗口。
关掉工作台窗口后，服务仍可继续处理任务。再次双击启动程序即可回到工作台。
已有任务库会自动加载。识别、翻译和中文配音在本机 CPU 上完成，模型随包提供。

批量制作
「X 帖子链接」每行输入一条，可批量导入。「本地视频」可多选文件。
输入视频后先选择音色和朗读风格，点「试听」比较；也可先选用「青禾 · 演讲」或「小满 · 甜美」。
勾选「原声＋中文字幕」或「中文配音＋中文字幕」，也可同时勾选两版，再点「开始翻译」。
首次默认仅选原声。原声版保留讲话和现场背景声，配音版使用选定的声音。
标准档和快速档均合成 24 kHz 语音。制作进度显示在「任务与历史」。
双选时，原声版先就绪即可下载。两版都完成后，可从同一时间点切换观看，
分别下载两份 MP4，或从「导出」下载双音轨 MP4，用 VLC 等播放器切换音轨。
历史任务也可调整音色、风格和输出版本并重新生成。
单条视频的下载或配音失败后，可在该任务重试，其他任务会继续处理。
下载和字幕处理中可暂停或停止任务。暂停后可手动继续，停止后保留历史。正在进行的请求会在下一个可中断点退出。

AI 切片与 X 长帖
在「视频与字幕」页处理视频。中文字幕就绪后，进入「切片与推文」页选模型、剪辑方式和目标片数。
可展开「切片前和 Agent 讨论」，让 Agent 先根据字幕列出观点、依据和时间段。继续发送要求可调整方案。点击「确认方案并切片」后才导出视频和长帖。
可以直接用自然语言改片数、主题和顺序。Enter 发送，Shift+Enter 换行。只追问选片理由时，Agent 会保留已有方案。讨论模式下每片 2–5 分钟。
「切片来源」可选原始视频、已完成的原声字幕版或中文配音版。AI 先分析字幕，再用时间码剪辑选中的版本。
切片保留该版本的音轨，已有中文字幕的成片不会再叠一层字幕。
切片在后台执行，进度和结果直接显示在本页。切换任务后，可以从历史记录回来看进度。
字幕分析按批保存，已导出的视频和已写完的长帖逐条保存。任务中断后，回到原任务点「从断点继续」，可切换模型后接着跑。
切片就绪即可预览视频和编辑长帖草稿。长帖并行生成，自动选模会在重写仍未通过检查时换模型。部分长帖仍失败时，从断点继续只补写缺少的长帖。
如已配置 CloudBase，可勾选「云端续存」，待初次备份完成后复制跨设备恢复链接。Windows 服务可用 XREAD_CLOUDBASE_KEY_FILE 指定密钥文件。恢复链接可读取该任务，建议自行保管。
百炼拒绝当前模型、模型不可用或被限流时，任务会自动尝试候补模型，页面显示实际使用的模型。
默认「自动选择」，模型输出被截断或格式无效时也会自动换模型。旧任务选自动后点「重试」可继续未完成的部分。
推文会结合视频标题和字幕引用有明确依据的人物观点或团队做法。
「观点混剪」按观点选出开场、论据和收束，可把原视频后面的关键句提前；也可选「顺序切片」。
两种方式都会先通读全文并提炼不同观点，再为每个观点找论据。开场寒暄和现场指令会被剔除。
长帖直接提出观点、论据和建议。可在编辑框修改，改稿保存在当前浏览器，可复制或下载当前 TXT。
批量 ZIP 提供生成时的结果。旧任务可点「重新生成」应用新版写作规则。
45 分钟以上的视频默认尝试生成 10 条混剪。顺序切片和混剪均按内容在 2–5 分钟之间取舍，保证单片论证完整。没有合适的拆分点时可保留整片。
FFmpeg 按剪辑顺序拼装 MP4 和 SRT。每一段剪完即可预览和下载，中文 X 长帖随后生成。篇幅以约 1000 字为参考，论证完整的短稿也会交付。
全部完成后也可一次下载 ZIP。
该功能联网调用阿里云百炼，提交字幕文字和时间戳。剪辑在本机完成。
可使用弹窗内的 API Key 输入框，或由本机设置 DASHSCOPE_API_KEY / XREAD_BAILIAN_KEY_FILE。
同一片段的长帖可复制到 X 核对后发布。

中文音轨
2.2 版的固定音色按女声和男声分组，共五个女声和三个男声。首次选择中文配音时，默认自然女声。
女声包括自然女声、清亮女声、青禾女声、云舒女声和小满女声。
男声包括原有的「男声」，以及松言男声和云舟男声。可用相同档位试听不同音色。
每个固定音色都可搭配「自然交谈」「演讲」或「甜美讲述」。先选音色、朗读风格和音质，
再点「试听」比较同一段话的停顿和语气。首次默认自然交谈，之后会记住主动选择。
选定固定音色后，整部视频由同一位合成说话人朗读。也可选「自动」按原讲话音域匹配，
此模式可能随原声改变。可以在「任务与历史」中打开旧视频，选好下次配音的音色后点「重新生成」。
系统以字幕时间轴为准逐句生成普通话，调整停顿和语速，生成 H.264 + AAC 的独立 MP4。
中文配音使用独立的普通话音轨，原声版保留原来的音轨。
配音会把独立出现的 Agent、Agents 读作「智能体」，把 AI 读作「人工智能」。
原画已有中文字幕时直接沿用画面里的字。缺少中文字幕时，
应用会在底部烧录一份中文字幕。自动判断可由「原画已有中文」手动指定。
原画字幕已印在视频中时，编辑译文会更新配音和独立字幕文件，原画文字保持原样。
长句或过密字幕可能需要加快朗读。可先在字幕文稿里缩短译文，再重新配音。

历史、修订与恢复
旧任务也可直接制作中文成片。编辑中文字幕后，应用将提醒重新配音。
相同源视频、声线和未修改的字幕句子复用已生成的语音片段。
程序重启后恢复排队或处理中断的任务。上传中断时需要重新选择本地文件。
任务数据保存在 %LOCALAPPDATA%\Xread\Library，每个任务独立保存原视频、字幕和成片。
请在停止程序、导出要保留的文件后再移动历史目录。

高级启动
在解压目录运行 runtime\python.exe -B -X utf8 server.py --port 8766 --open 可更改端口。
设置 XREAD_LIBRARY 可指定任务库。同一任务库同时允许一个服务运行。
