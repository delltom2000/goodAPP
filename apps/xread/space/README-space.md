# Xread 2.3 中文视频译制台

粘贴公开 X 帖子链接，或上传一段本地英文视频，就能听原声看中文字幕，也能制作普通话配音版。直接打开工作台即可开始。[进入在线工作台](https://dellweb3-translateall.hf.space)

## 第一次使用

1. 在「X 帖子链接」中每行粘贴一个 X 帖子，或点「本地视频」一次选择多个文件。链接读取失败时，可以上传已保存的视频。
2. 先选音色和朗读风格，点「试听」比较停顿和语气。五个女声、三个男声都能搭配「自然交谈」「演讲」或「甜美讲述」，也可一键选用「青禾 · 演讲」或「小满 · 甜美」。
3. 勾选「原声＋中文字幕」或「中文配音＋中文字幕」，也可以两项都选。首次默认仅选原声。点「开始翻译」，到「任务与历史」查看每条视频的进度。
4. 在播放器中切换源视频和已就绪的成片。双选时，原声版先完成就可下载；两版完成后，也可从「导出」下载双音轨 MP4，在 VLC 等播放器中切换音轨。需要双语 SRT 时，先点「双语对照」再导出。

已有中英文字幕时，Xread 会优先复用。只有英文时，系统保留英文时间轴并翻译；缺少可用字幕时，则先识别英文对白。原画已印有中文的片段可选「原画已有中文」，避免叠加第二层文字。

## AI 切片与 X 长帖

在「视频与字幕」页导入和校对。字幕就绪后，进入「切片与推文」并输入已登记的手机号。可从原始视频、原声字幕版和中文配音版中选择已就绪的版本。百炼先根据字幕时间码提炼观点，FFmpeg 再剪接所选版本并重排字幕。顺序切片和观点混剪均按内容在 2–5 分钟之间取舍，无法拆成独立论证时保留整片。45 分钟以上的视频默认尝试生成 10 条。[FFmpeg 项目](https://github.com/FFmpeg/FFmpeg)

每段剪完即可预览或下载，并可先编辑对应的长帖草稿。长帖并行生成，约 1000 字是写作目标，论证完整的短稿也会交付。自动选模会在长帖重写仍未通过复核时换模型。失败项会显示原因，从断点继续只补写缺少的长帖。改稿保存在当前浏览器，可复制或下载当前 TXT。

打开「切片前和 Agent 讨论」后，可以用自然语言调整片数、主题和顺序，或追问选片理由。Enter 发送，Shift+Enter 换行。讨论模式每片 2–5 分钟，核对字幕依据和时间线后点「确认方案并切片」。

字幕分析按批保存，成片和长帖逐条保存。任务中断且文件仍在时，在原任务点「从断点继续」。
启用 CloudBase 后，可在生成前勾选「云端续存」。初次备份完成后，复制恢复链接，在另一台设备的同一在线工作台打开，恢复选定的视频、字幕和最近一次成功同步的断点。持有链接即可读取该备份。

## 云端会话与文件

上传的视频在 Space 的 CPU 上处理。任务按浏览器会话隔离，换浏览器或清除网站数据后可能无法再打开之前的记录。默认使用临时存储，Space 重启或重建时会清除任务文件。管理员可以把私有可写存储卷挂载在 `/data`，或通过 `XREAD_SPACE_DATA` 指定该卷内的任务目录，让同一浏览器在重启后继续。会话清理仍会移除过期文件。**需要保留的成片和字幕，请在处理完成后下载。**

CloudBase 使用 PG 模式的私有 `xread-checkpoints` 存储桶。管理员将 CloudBase 服务端 API Key 配置为 Space Secret `XREAD_CLOUDBASE_KEY`。开启续存会产生 CloudBase 的存储和流量用量。

Space 使用免费的 CPU Basic 算力。长视频的识别、配音和转码需要排队；空间休眠后，首次打开可能需要等待启动。[Hugging Face Spaces 硬件与运行说明](https://huggingface.co/docs/hub/spaces-overview)

## Windows 本地版

要在自己的电脑上处理和保存视频，请下载 Windows x64 压缩包，完整解压后双击 `Start Xread.cmd`。浏览器会打开本机工作台，识别、翻译和配音模型随包提供。下载 X 视频需要联网，已保存的视频可以在本机离线处理。[下载 Windows x64 版](https://dellweb3-translateall.hf.space/download/windows) · [查看 goodAPP 项目源码](https://github.com/delltom2000/goodAPP/tree/main/apps/xread)
